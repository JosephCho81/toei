=====================================================
  정산 원본데이터 입력 방법 (꼭 읽어주세요)
=====================================================

[가장 중요한 규칙]
- 모르거나 서류에 없는 칸은 그냥 "비워두세요". 억지로 채우지 마세요.
- 아는 것, 서류에 적힌 것만 그대로 옮겨 적으세요.
- 날짜는 반드시 2026-03-15 형식 (연-월-일).
- 금액/숫자는 콤마(,) 없이 숫자만. (예: 2500000  O / 2,500,000 X)
- 파일은 Excel에서 열어 "다른 이름으로 저장 > CSV UTF-8" 로 저장.

-----------------------------------------------------
[파일 1] 01_원본데이터_제품.csv  =  "제품 한 개 = 한 줄"
-----------------------------------------------------
한 차수(예: 40차)에 제품이 여러 개면, 제품 수만큼 줄을 만드세요.
거래정보(차수~LC결제총액)는 같은 차수면 매 줄에 똑같이 반복해서 적으세요.

* 어디서 찾는지 *
- 차수번호/차수명/발주번호 : 발주서
- 제조사                  : 발주서 (만든 회사)
- LC번호/개설일/만기일     : LC(신용장) 서류
- 에이원입금일            : 에이원에서 돈 들어온 날
- 통관일/수입신고번호/통관환율/통관금액/과세가격 : 수입신고필증
- 한국은행환율            : 한국은행 고시환율 (모르면 비움)
- 마진율/환차부담         : 모르면 비움 (기본 50)
- 클로징일/LC결제총액      : 정산 마감 서류 (모르면 비움)
- 제품사양/종류/색상/사이즈/개당단가/수량 : 인보이스(Invoice)
- 컨테이너번호~CBM         : B/L, 패킹리스트, 포워더 서류
  (한 차수에 컨테이너 1개면 첫 줄에만 적고 나머지는 비워도 됨)

-----------------------------------------------------
[파일 2] 02_비용항목.csv  =  "비용 한 개 = 한 줄"
-----------------------------------------------------
운임, 통관료, 관세, 부가세, LC수수료 등 들어간 비용을 한 줄에 하나씩.
- 차수번호 : 어느 차수 비용인지 (예: 40)
- 비용항목명 : 서류에 적힌 이름 그대로 (예: 해상운임)
- 금액원   : 원화 금액, 숫자만
- 구분    : 운송 / 통관 / LC  중 하나 (모르면 비움)

* 예시 행들은 참고용입니다. 실제 입력 후 예시 줄은 지우세요. *
