## 읽는 법

파일이 60줄을 넘으면 통째로 열지 않는다. 목차를 먼저 보고 필요한 절만 가져온다.

```bash
grep -n '^#' docs/차수-이슈.md      # 목차와 줄번호
sed -n '40,72p' docs/차수-이슈.md   # 그 절만
grep -n '37차' docs/차수-이슈.md     # 차수로 바로
```

## 세 줄로 줄인 판단 기준

금액이 걸린 판단을 할 때 이 셋만은 먼저 안다. 나머지는 위 표에서 찾는다.

1. **금액이 셋이다** — 실제 청구액 / 담당자 확정금액 / 시스템 계산값.
   차이도 셋이라 한 칸에 합치지 않는다 (`docs/화면-규칙.md`)
2. **규약의 원본은 `lib/calculations/` 다.** 엑셀도 원본 문서도 아니다.
   화면·PDF·대시보드는 그 함수를 **호출만** 한다 — 공식을 다시 쓰면 두 벌이 어긋난다
3. **2026-09-04 이전 산출물의 금액은 구규약 기준이다.**
