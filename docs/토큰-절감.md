# 토큰 절감

## 왜 비싼가

비용의 **약 97%가 캐시 읽기**다. 파일을 읽어서가 아니라 매 턴마다 그때까지의 전체 컨텍스트를
다시 읽기 때문이다. 컨텍스트가 88K까지 자라면 그 뒤 턴은 전부 88K씩 재전송한다.
(2026-08-31 실측: 캐시 읽기 1,282,678 토큰 / 출력 18,099 / $1.98)

**비용 = 컨텍스트 크기 × 턴 수.** 후반 턴이 초반보다 몇 배 비싸다.

## 작업 규칙

- **작업 단위로 `/clear`.** 감사 → 문서작성 → 검토를 한 세션에 이어붙이지 않는다.
  `docs/정산-현황.md` 와 `README.md` 가 있으면 새 세션에서 맥락을 다시 캐낼 필요가 없다
- **한 번의 도구 출력이 3,000 토큰을 넘기면 그 세션 내내 매 턴 재전송된다**
  - 전 차수 표를 통째로 찍지 말고 **불일치 행만** 출력
  - `git show` 전문 대신 `--stat`
  - CSV·긴 파일은 필요한 블록만 `sed -n` / `offset`·`limit`
  - DB 조회는 전체 스캔 대신 좁은 쿼리로
- 서브에이전트는 사용자가 요청하거나 정말 독립 병렬 작업일 때만

## 미적용 — 글로벌 설정 (자동 모드로 못 고친다, 수동 적용 필요)

매 턴 실리는 고정 오버헤드가 약 20,000 토큰이고 그중 절반이 아래 둘이다.

**1. 플러그인 끄기 (~7,200 토큰/턴)** — `~/.claude/settings.json`

```json
"enabledPlugins": {
  "vercel@claude-plugins-official": false,
  "ui-ux-pro-max@ui-ux-pro-max-skill": false
}
```

배포는 `git push` 로 하고 ui-ux-pro-max 는 쓰지 않는다.
`extraKnownMarketplaces` 의 `llm-wiki`·`ui-ux-pro-max-skill` 항목도 함께 제거.
되돌리려면 `true` 로 바꾸면 된다.

**2. `autoMode.environment` 제거 (~1,100 토큰/턴)** — 같은 파일

Firebase·이카운트·a1system 내용이 24줄 들어 있다. 이 프로젝트와 무관한데 매 턴 실린다.
토큰 낭비이면서 오판 위험이기도 하다. `autoMode` 안의 `environment` 키만 삭제하고
`allow`·`soft_deny` 는 그대로 둔다.
