# 토큰 절감

## 왜 비싼가

비용의 **약 97%가 캐시 읽기**다. 파일을 읽어서가 아니라 매 턴마다 그때까지의 전체 컨텍스트를
다시 읽기 때문이다. 컨텍스트가 88K까지 자라면 그 뒤 턴은 전부 88K씩 재전송한다.
(2026-08-31 실측: 캐시 읽기 1,282,678 토큰 / 출력 18,099 / $1.98)

**비용 = 컨텍스트 크기 × 턴 수.** 후반 턴이 초반보다 몇 배 비싸다.

## 작업 규칙

- **작업 단위로 `/clear`.** 감사 → 문서작성 → 검토를 한 세션에 이어붙이지 않는다.
  `docs/정산-현황.md` 와 `README.md` 가 있으면 새 세션에서 맥락을 다시 캐낼 필요가 없다
- **한 번의 도구 출력이 3,000 토큰을 넘기면 그 세션 내내 매 턴 재전송된다**
  - 전 차수 표를 통째로 찍지 말고 **불일치 행만** 출력
  - `git show` 전문 대신 `--stat`
  - CSV·긴 파일은 필요한 블록만 `sed -n` / `offset`·`limit`
  - DB 조회는 전체 스캔 대신 좁은 쿼리로
- 서브에이전트는 사용자가 요청하거나 정말 독립 병렬 작업일 때만

## 적용 완료 — 글로벌 설정 (2026-09-04)

매 턴 실리던 고정 오버헤드 약 20,000 토큰 중 **약 8,300 토큰을 걷어냈다.**
`~/.claude/settings.json` 이 3,616자 → 619자가 됐다 (백업: `settings.json.bak-20260904-141502`).

| 지운 키 | 내용 | 절감 |
|---|---|---|
| `enabledPlugins` | `vercel@claude-plugins-official`, `ui-ux-pro-max@ui-ux-pro-max-skill` | ~6,900 (스킬 설명문 + Vercel 세션시작 훅) |
| `extraKnownMarketplaces` | `llm-wiki`, `ui-ux-pro-max-skill` | — (플러그인이 꺼지면서 같이 정리) |
| `autoMode.environment` | Firebase·이카운트·Oracle VM 등 **a1system 프로젝트 내용** 24줄 | ~1,100 |

`autoMode.allow`·`soft_deny`, `permissions`, `model`, `tui` 는 그대로 뒀다.

- **다음 세션부터 적용된다.** 세션은 시작할 때 읽은 설정으로 돈다
- 플러그인 파일은 `~/.claude/plugins/cache/` 에 남아 있다 — 로드되지 않으니 토큰은 안 쓰고 디스크만 쓴다.
  되돌리려면 `enabledPlugins` 에 다시 넣고, 디스크에서도 지우려면 `claude plugin uninstall <plugin>@<marketplace>`
- 배포는 `git push` 로 하므로 vercel 플러그인이 없어도 막히는 것이 없다

⚠️ **이 파일은 문법이 깨지면 모든 설정이 조용히 무효화된다.** 문자열 치환 말고 JSON 파서를 거쳐 쓸 것.
확인도 파서로 한다 — `jq` 는 이 환경에 설치돼 있지 않아, `jq ... && echo OK || echo FAIL` 로 검사하면
명령 실패가 성공처럼 읽힌다.
